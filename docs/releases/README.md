# Release notes

Full per-version release notes, newest first. `.github/workflows/publish-images.yml` publishes
each of these verbatim as the GitHub Release body on its matching `vX.Y.Z` tag push, so a release's
title (the file's own `# ` heading, minus the trailing `(major|minor|patch)` tag) has to stay the
first line. For the condensed, single-file version history see [CHANGELOG.md](../../CHANGELOG.md)
at the repo root.

There is no `RELEASE_NOTES_v2.5.0.md` — 2.5.0 ("Sync you can actually trust") shipped inside the
2.6.0 tag and was never released on its own; see `CHANGELOG.md` for that release's full scope.
